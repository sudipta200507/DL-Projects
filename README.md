# Deep Learning Projects

Hands-on deep-learning projects covering CNNs, transfer learning, LSTM networks and transformers across vision, NLP and time series.

Projects:
- 01-cifar10-cnn — CNN image classification
- 02-fashion-transfer-learning — transfer learning
- 03-sms-spam-lstm — LSTM NLP
- 04-ag-news-transformer — transformer text classification
- 05-bike-demand-lstm — LSTM time-series forecasting

Clone: `git clone https://github.com/sudipta200507/DL-Projects.git`

Each project has its own README, requirements and training/inference workflow. TensorFlow Datasets provides documented public datasets such as CIFAR-10 and Fashion-MNIST.
